E55 두 번째 AR->DLM 짝: DiffuLLaMA-7B (확산) / LLaMA-2-7B (AR 부모)   2026-11-19
(하네스가 .md 쓰기를 막아 .txt 로 씀.  숫자: e55_summary.json)

1. 샘플러 (e55_dllm.py) 확인
- DiffuLLaMA 는 HF 의 보통 LlamaForCausalLM 이고 따로 붙은 코드가 없다.  양방향 주의는 4D 전부-참 마스크로 줌 (HKUNLP/DiffuLLaMA 의 attn_mask_ratio=1.0 과 같음).
- 로짓 정렬: 문장 안 토큰 하나를 가렸을 때, 그 토큰을 '앞 위치 출력' 이 맞힌 경우 107/110, '자기 위치 출력' 이 맞힌 경우 15/110 -> Dream 처럼 한 칸 밀어 씀 (답 칸 0 = 프롬프트 끝 위치 출력).
- 양방향 확인: 뒤 토큰을 바꾸면 앞 위치 로짓이 바뀜 (최대 차이: 양방향 5.8, 인과 마스크 0).  "The capital of [M] is Berlin/Tokyo/Rome" 을 Germany/Japan/Italy 로 채움.
- Dream 과 같은 설정: 캔버스 32, 32 step, temperature 0, topk_margin (top_k 50 으로 거른 뒤 softmax, top1-top2, bf16), Dream 과 같은 칸 수 일정 (step 0 에는 0 칸, 첫 확정은 step 1).  마스크 토큰 'ти' (id 811).
- 출력은 말이 된다 (예: 'Cole Porter', 'San Francisco', Base 모델이라 답 뒤에 'Question: ...' 을 이어 씀).  e55_sampler_check.json 참고.
- Dream 과 다른 점: (a) 'ти' 가 실제 어휘라서, 마스크 여부를 토큰 비교 대신 캔버스 안에서 따로 추적.  (b) top1-top2 를 전체 정렬 대신 topk(2) 로 구함 (값은 같음).  lm_head 는 캔버스 위치에만 씀 (logits_to_keep).  (c) 묶음 크기 64 (Dream 16).  (d) 프롬프트에 BOS 포함 (LLaMA 토크나이저 기본값).
- bf16 이라 묶음 구성이 바뀌면 답이 바뀔 수 있다.  묶음이 다른 실행끼리 비교하면 답 일치 73% (step 0 칸 0 argmax 는 127/128 일치, 금 로짓 차이 평균 0.04).  그래서 개입은 같은 묶음의 base 와만 비교했다.  B 단계 base 와 A 단계 base 는 답 99.1%, 정오 99.7% 일치.
- 금 첫 토큰 규칙: LLaMA sentencepiece 는 tok(' '+gold) 앞에 '▁' (29871) 하나를 따로 붙이므로, Dream 규칙을 그대로 쓰면 모든 금 토큰이 '▁' 가 된다.  그래서 '프롬프트 + " " + gold' 를 통째로 토큰화해 프롬프트 바로 다음 토큰을 썼다 (= tok(gold)[0], 예 '▁politician').  오답 행 가운데 금 토큰이 '▁' 하나만인 행은 0.

2. 실행 (PopQA 55,225 행 전부, 같은 프롬프트, 같은 채점기)
- A 단계: DiffuLLaMA base 전체 (k/5 를 정함).  B 단계: DiffuLLaMA 1~4/5 사실의 7,965 행에 base 와 칸0먼저를 같은 묶음에서 돌림 (E27b 방식).  LLaMA-2: greedy, 새 토큰 32, 첫 위치의 금 첫 토큰 순위와 log 확률도 기록.
- 정확도: DiffuLLaMA 11.78%, LLaMA-2 20.07%.  (Dream/Qwen 보다 훨씬 낮음)
- 사실별 k/5 (0,1,2,3,4,5): DiffuLLaMA 8882/542/372/349/330/570 -> 1~4/5 사실 1,593 (행 7,965).  LLaMA-2 7927/537/364/381/507/1329 (1~4/5 1,789).
- DiffuLLaMA 1~4/5 오답 (entity/broken) 4,306 행 (사실 1,592): DLM 고유 2,349, 공유 1,957 (abstain 7 행 제외).  표본은 150 사실 기준보다 훨씬 큼.

3. H55.1 (step 0 칸 0 금 1 위: DLM 고유 > 공유): 참
- 30.3% 대 9.7%, 차이 +20.7 [17.8, 23.5] (사실 군집 부트스트랩 B=4000).  같은 사실 안 (454 사실): +8.8 [5.6, 12.2].
- top-5 67.5 대 37.5, 순위 중앙값 2 대 9, '1 위였는데 칸 0 이 금이 아님' 16.3 대 5.3.  Dream (E49) 27.8 대 12.6 과 같은 모양.
- LLaMA-2 금 logprob 5 분위 x 답 토큰 수로 층화 (MH, B=2000): -1.2 [-3.9, 1.6] -> 사라진다.  Dream 의 E57 결과와 같다: step 0 의 후보 우위는 부모가 금 토큰을 얼마나 높게 보는지로 설명된다 (DLM 고유 행의 LLaMA-2 금 1 위 76.4% 대 6.1%).

4. H55.2 (칸0먼저 복구: DLM 고유 > 공유): 참
- 24.4% 대 7.7%, 차이 +16.7 [14.3, 19.2].  같은 사실 안: +11.0 [7.7, 14.4].  Dream (E49c) 30.2 대 11.4 와 비슷하다.
- 층화 (LLaMA-2 금 logprob 5 분위 x 답 토큰 수, MH): +10.3 [7.2, 13.4] -> 남는다 (Dream E57 의 +10.8 [6.5, 15.1] 와 같은 크기).
- 서술: 칸0먼저는 1~4/5 정답 행도 깨뜨린다.  같은 문구를 LLaMA-2 가 틀린 행에서 59.7%, 맞힌 행에서 25.5% 가 깨진다 (+34.2 [30.2, 38.3]).  1~4/5 전체 정확도: k1 20.1->19.5, k2 40.1->35.2, k3 59.9->49.2, k4 79.9->67.2.  순서를 바꾸면 양쪽으로 작용한다 (Dream H50.4 와 같은 방향).

5. 결론
두 번째 AR->DLM 짝에서도 Dream 결과가 그대로 나온다.  (1) DLM 고유 실패는 step 0 에 정답 후보가 앞서 있었는데, 이 차이는 부모 AR 의 금 토큰 확률로 설명된다.  (2) 칸 0 을 먼저 확정하면 DLM 고유 실패가 더 많이 고쳐지고, 이 차이는 부모 확률과 답 길이로 층화해도 남는다.
주의: 두 모델 모두 정확도가 낮다.  B 단계 행은 A 단계의 k/5 로 골랐다.

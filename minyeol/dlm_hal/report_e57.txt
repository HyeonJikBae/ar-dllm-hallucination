== 판정 ==

핵심:
1. 'step 0 에 정답 후보가 있음' (E49) 은 부모 Qwen 이 같은 문구에서 금 첫 토큰에 주는 확률로 완전히 설명된다.  -> 물려받은 시작 상태이지 DLM 고유 성질이 아니다.
2. 순서 개입 복구의 경로 차이 (E50 전체 규모, E49c) 는 같은 층화 뒤에도, Dream 자신의 step 0 금 순위로 층화해도 남는다.  -> DLM 고유성의 증거는 순서 개입 쪽에 있다.
3. 층 20 probe 는 'step 0 에 금 첫 토큰을 얼마나 앞세우나' (금 로짓) 를 넣으면 더하는 정보가 0.
